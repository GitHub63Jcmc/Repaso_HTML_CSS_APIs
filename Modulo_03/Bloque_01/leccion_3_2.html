3.2 Creación de formas básicas, líneas y trazados

Bloque 1 · Gráficos y Dibujo con la API Canvas

La única forma primitiva directa en canvas es el rectángulo; todo lo demás se construye con trazados (paths): secuencias de puntos y curvas que después se rellenan o se perfilan.

Métodos principales de trazados

Método Qué hace
fillRect(x, y, ancho, alto) Dibuja un rectángulo relleno.
strokeRect(x, y, ancho, alto) Dibuja solo el contorno del rectángulo.
clearRect(x, y, ancho, alto) Borra una zona del lienzo (la deja transparente).
beginPath() Inicia un trazado nuevo.
moveTo(x, y) / lineTo(x, y) Sitúa el lápiz sin pintar / traza una línea hasta el punto.
arc(x, y, radio, angIni, angFin) Dibuja arcos y círculos (ángulos en radianes; una circunferencia completa es 2*PI).
closePath() Cierra el trazado uniendo el último punto con el primero.
fill() / stroke() Pinta el trazado actual relleno o contorno. Sin esta llamada, el trazado no se ve.
