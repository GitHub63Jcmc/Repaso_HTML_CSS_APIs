3.1 Introducción al elemento canvas y su contexto de dibujo

Bloque 1 · Gráficos y Dibujo con la API Canvas

La etiqueta <canvas> reserva en la página un lienzo de píxeles sobre el que se dibuja desde JavaScript: gráficos, juegos, editores de imagen, firmas digitales... Se declara con sus dimensiones (ejemplo: <canvas id="lienzo" width="600" height="400"></canvas>). Si no se indica, mide 300x150 y el texto interior sirve de alternativa para navegadores sin soporte. Conviene fijar el tamaño con los atributos, no solo con CSS: escalarlo con CSS deforma y pixela el dibujo.

El Contexto de Dibujo (2D)

El lienzo por sí solo no hace nada; para dibujar se pide su contexto, el objeto que contiene todos los métodos de dibujo. El bidimensional se obtiene con const ctx = lienzo.getContext('2d'). Todo se sitúa mediante coordenadas: el origen (0,0) está en la esquina superior izquierda. La X crece hacia la derecha y la Y hacia abajo. Existen otros contextos para gráficos 3D acelerados (webgl, webgl2 y el más reciente webgpu), que quedan fuera del alcance de este curso.
