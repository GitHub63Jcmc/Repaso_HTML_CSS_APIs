3.3 Gestión de colores, estilos y renderizado de texto

Bloque 1 · Gráficos y Dibujo con la API Canvas

Antes de dibujar se configura el pincel: fillStyle fija el color de relleno y strokeStyle el del contorno; ambos aceptan cualquier color CSS (nombres, hexadecimal, rgba()). El grosor de línea se ajusta con lineWidth, los extremos y las uniones con lineCap y lineJoin, y la transparencia global con globalAlpha.

También hay degradados propios —se crean con createLinearGradient() o createRadialGradient(), se añaden paradas con addColorStop() y se asignan a fillStyle—, rellenos de patrón con createPattern() y sombras con shadowColor y shadowBlur.

Renderizado de Texto

El texto se dibuja como gráficos: font = 'bold 24px Poppins' define la letra con sintaxis CSS, fillText('Hola', x, y) lo pinta relleno y strokeText() solo el contorno. textAlign y textBaseline controlan la alineación respecto al punto de contexto, y measureText(texto) devuelve un objeto de métricas cuya propiedad width es el ancho que ocupará la cuerda, imprescindible para centrar o ajustar composiciones.

IDEA CLAVE: Canvas pinta píxeles, no objetos: una vez dibujado algo, el lienzo no lo recuerda. Para mover una figura hay que borrar y redibujar (en animaciones, con requestAnimationFrame). Y como es una imagen, aporta siempre una alternativa textual accesible para quien no pueda verla.
