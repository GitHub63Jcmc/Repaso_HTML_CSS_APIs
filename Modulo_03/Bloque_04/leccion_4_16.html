3.16 Introducción a Web Sockets para comunicación bidireccional

Bloque 4 · Comunicación y Conectividad en Tiempo Real

HTTP funciona por turnos: el navegador pregunta, el servidor responde y la conversación se cierra. Para un chat, un juego multijugador o un panel de cotizaciones, ese modelo obliga a preguntar sin parar (*polling*), con retardo y tráfico desperdiciado.

WebSocket lo sustituye por una conexión permanente y bidireccional: tras un apretón de manos inicial sobre HTTP, el canal queda abierto y cualquiera de las dos partes puede enviar mensajes en cualquier momento, con latencia mínima.

USO SENCILLO DESDE JS: Se instancia de forma muy simple: const ws = new WebSocket('wss://servidor.ejemplo/canal'). A partir de ahí, cuatro eventos llevan toda la lógica: open, message, error y close. Se envía con ws.send(texto).
