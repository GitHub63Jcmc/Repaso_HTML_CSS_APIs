3.17 Microdatos y API DOM para la estructuración de datos

Bloque 4 · Comunicación y Conectividad en Tiempo Real

Los microdatos son un mecanismo de HTML5 para etiquetar el significado de los datos visibles de la página, de modo que las máquinas —sobre todo los buscadores— los entiendan[cite: 14]: qué es un producto, su precio, la valoración, un evento y su fecha[cite: 14]. Se usan tres atributos principales[cite: 14]: itemscope (declara un elemento con los datos)[cite: 14], itemtype (indica el tipo según un vocabulario como schema.org)[cite: 14] e itemprop (marca cada propiedad dentro del ítem)[cite: 14].

La API DOM (Document Object Model) es la representación viva del documento: el navegador convierte el HTML en un árbol de nodos que JavaScript puede consultar y modificar[cite: 14].

SEGURIDAD EN EL DOM: Para insertar texto usa siempre textContent y reserva innerHTML solo para confianza, ya que insertar texto ajeno como HTML abre la puerta a ataques de inyección de scripts (XSS)[cite: 14].
