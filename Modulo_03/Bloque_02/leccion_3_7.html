3.7 Almacenamiento local con Web Storage: localStorage y sessionStorage

Bloque 2 · APIs de Geolocalización y Almacenamiento

Web Storage permite guardar pares clave-valor en el navegador, por origen (dominio + protocolo + puerto), con una capacidad orientativa de unos 5 MB, muy superior a la de las cookies. Su API es idéntica en sus dos variantes: setItem('clave', 'valor') guarda, getItem('clave') recupera, removeItem('clave') borra una clave y clear() vacía todo.

Solo almacena cadenas de texto; para objetos se usa JSON.stringify() al guardar y JSON.parse() al leer.

localStorage

Persistente: Los datos sobreviven al cierre del navegador y no tienen fecha de caducidad. Usado para preferencias de usuario, temas, etc.

sessionStorage

Temporal: Vive mientras dura la pestaña; al cerrarla, se borra. Cada pestaña tiene su propia copia independiente.
