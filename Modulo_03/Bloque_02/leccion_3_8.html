3.8 Introducción a IndexedDB para bases de datos en el cliente

Bloque 2 · APIs de Geolocalización y Almacenamiento

Cuando los datos crecen o necesitan estructura, Web Storage se queda corto. IndexedDB es la base de datos del navegador que guarda objetos JavaScript completos (incluidos archivos y binarios) en almacenes de objetos, con índices para buscar por cualquier campo, transacciones que garantizan la integridad y una capacidad que se mide en cientos de megabytes o más[cite: 19].

Su API es asíncrona y funciona por peticiones y eventos[cite: 19]. Se abre con indexedDB.open('MiDB', 1), y el evento onupgradeneeded es el único lugar donde se define la estructura mediante createObjectStore()[cite: 19].

TRANSACCIONES Y ACCESO: Las operaciones se hacen dentro de una transacción con bd.transaction('tareas', 'readwrite') y objectStore('tareas').add(objeto), con métodos análogos get(), put() y delete() para recorrer registros[cite: 19].
