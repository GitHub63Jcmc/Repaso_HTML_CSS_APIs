3.6 API de Geolocalización: obtención de coordenadas y seguimiento

Bloque 2 · APIs de Geolocalización y Almacenamiento

La API de Geolocalización permite a una web conocer —con previo permiso del usuario— la posición del dispositivo, combinando GPS, redes wifi y antenas de telefonía. Es la base de los mapas, los buscadores de tiendas cercanas o el seguimiento de rutas deportivas.

El método principal es getCurrentPosition(exito, error, opciones). Si todo va bien, la función de éxito recibe un objeto coords cuya propiedad coords.latitude, longitude, accuracy (precisión en metros) y, según el dispositivo, altitud, rumbo y velocidad.

SEGURIDAD Y CONTEXTOS SEGUROS (HTTPS): El navegador muestra el aviso de permiso y, si el usuario lo rechaza, la aplicación debe seguir funcionando con una alternativa (por ejemplo, pedir el código postal). Además, geolocalización solo funciona en contextos seguros (HTTPS).
