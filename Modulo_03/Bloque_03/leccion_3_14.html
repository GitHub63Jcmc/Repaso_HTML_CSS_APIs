3.14 API Fullscreen y Web Notifications para mejorar la experiencia

Bloque 3 · APIs de Interactividad y Rendimiento

La API Fullscreen lleva cualquier elemento a pantalla completa: videos, galerías, juegos o paneles de control. Se solicita sobre el elemento con element.requestFullscreen() y se sale con document.exitFullscreen().

La API Web Notifications muestran avisos del sistema fuera de la página. Pide permiso con Notification.requestPermission() —que devuelve una promesa con *granted*, *denied* o *default*— y, concedida, se lanza con new Notification('Título', { body: 'Detalle' }).

GESTO DE USUARIO OBLIGATORIO: Tanto el modo pantalla completa como la petición de notificaciones exigen la acción directa del usuario (un clic) por motivos de seguridad; no se pueden invocar automáticamente al cargar la página.
