3.13 Implementación de funcionalidades drag and drop

Bloque 3 · APIs de Interactividad y Rendimiento

La API de arrastrar y soltar integra en el navegador un gesto natural del escritorio: mover tarjetas entre columnas, ordenar listas o soltar archivos para subirlos[cite: 13]. Participan dos papeles: el elemento arrastrable (que se marca con el atributo draggable="true") y la zona de destino, que debe declarar que acepta soltar[cite: 13].

Eventos clave del proceso:

  • dragstart: se dispara en el elemento al empezar el arrastre; aquí se guardan los datos con event.dataTransfer.setData('text/plain', id)[cite: 13].
  • dragover: se dispara continuamente sobre la zona de destino; hay que llamar a event.preventDefault() porque por defecto los navegadores no permiten soltar[cite: 13].
  • drop: el suelto propiamente dicho; se recuperan los datos con getData() y se actúa (mover la tarjeta, leer el archivo)[cite: 13].
CONSIDERACIÓN PROFESIONAL: El gesto de arrastre no existe para quien navega con teclado, así que ofrece siempre una alternativa accesible (botones de mover, menús contextuales)[cite: 13].
