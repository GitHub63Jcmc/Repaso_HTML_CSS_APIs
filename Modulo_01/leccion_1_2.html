Módulo 1. NUEVAS ETIQUETAS Y ATRIBUTOS DE HTML5

1.2 De HTML a HTML5: qué cambió de verdad

HTML5 no fue solo una versión más. Se asumió que la web se había convertido en una plataforma de aplicaciones y actuó en consecuencia. Tres decisiones lo resumen: simplificar lo que había, dar significado al marcado y llevar al navegador capacidades que antes exigían complementos.

Comparativa: Antes vs Con HTML5

Asunto Antes Con HTML5
Declaración del doc Línea larga con DTD externo <!DOCTYPE html>
Codificación <meta http-equiv="Content-Type"...> <meta charset="utf-8">
Estructura Divisiones genéricas con clases (div) Etiquetas semánticas: header, nav, article...
Vídeo y audio Plugins externos (Flash, Silverlight) Etiquetas nativas del navegador
Gráficos Imágenes preparadas o complejas Lienzo de dibujo (Canvas) y SVG vectorial
Validación formularios Siempre a mano con JavaScript Nativa, con atributos en el propio HTML
Guardar datos Cookies limitadas e enviadas en cada petición Almacenamiento propio (Web Storage API)
Etiquetas de aspecto Centrar o cambiar letra desde el HTML Retiradas: trabajo exclusivo de CSS

Cómo leer un documento mal escrito

HTML5 especificó exactamente cómo debe interpretarse el código imperfecto. Antes, cada navegador improvisaba ante un error de sintaxis; ahora el procedimiento de lectura está definido en la norma, asegurando que todos los navegadores construyan el mismo árbol DOM.

💡 IDEA CLAVE: Compatibilidad hacia atrás

HTML5 se declaró compatible hacia atrás. Una página escrita hace veinte años sigue funcionando hoy. La forma natural de trabajar con las novedades es la mejora progresiva: construir para que funcione en todas partes y añadir encima lo que cada navegador sepa aprovechar.

HTML5 como Estándar Vivo (Living Standard)

HTML5 tampoco se publica ya por versiones numeradas. La norma es un estándar vivo que se actualiza de forma continua. Existen tablas de compatibilidad pública para consultar soporte por función, además de comprobaciones en CSS (@supports) o JavaScript previo uso de APIs.
