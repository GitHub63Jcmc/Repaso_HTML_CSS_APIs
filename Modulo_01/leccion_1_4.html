Módulo 1. NUEVAS ETIQUETAS Y ATRIBUTOS DE HTML5

1.4 Nuevos elementos multimedia: video, audio y source

Hasta HTML5, reproducir un vídeo o audio exigía plugins externos como Flash[cite: 10]. Las etiquetas <video> y <audio> incorporaron la reproducción multimedia directamente al navegador sin instalar nada[cite: 10]. Ambas funcionen con el atributo src o con etiquetas <source> hijas[cite: 10]. El texto escrito entre la apertura y el cierre solo se muestra en navegadores antiguos no compatibles[cite: 10].

La etiqueta <video>

Inserta un reproductor de vídeo directo en la página[cite: 10].

  • Ejemplo básico: <video src="clip.mp4" controls width="680"></video>[cite: 10]
  • Atributos más usados:
    • controls: Muestra los controles de reproducción del navegador[cite: 10].
    • autoplay: Intenta reproducir el contenido automáticamente al cargar[cite: 10].
    • loop: Repite la reproducción en bucle[cite: 10].
    • muted: Inicia la reproducción sin sonido[cite: 10].
    • poster: Imagen que se muestra antes de reproducir el vídeo[cite: 10].
  • Formatos estándar: MP4 (códec H.264) y WebM[cite: 10].

La etiqueta <audio>

Inserta un reproductor de sonido nativo en el documento[cite: 10].

  • Ejemplo básico: <audio src="tema.mp3" controls></audio>[cite: 10]
  • Atributos principales: Comparte controls, autoplay, loop y muted[cite: 10]. Añade preload (opciones: none, metadata o auto) para gestionar la descarga previa del archivo[cite: 10].
  • Formatos universales: MP3, OGG y AAC[cite: 10].

Etiquetas <source> y <track>

  • <source>: Permite colocar varias opciones de archivo con formatos distintos dentro de un vídeo o audio[cite: 10]. El navegador recorre la lista y reproduce la primera alternativa compatible[cite: 10].
    <source src="video.webm" type="video/webm">[cite: 10]
  • <track>: Añade subtítulos o transcripciones sincronizadas en formato WebVTT para mejorar la accesibilidad[cite: 10].

💡 IDEA CLAVE: Reproducción automática (Autoplay)

Los navegadores actuales bloquean la reproducción automática con sonido para no molestar al usuario[cite: 10]. Si necesitas usar autoplay, debes combinarlo siempre con el atributo muted[cite: 10].
