Módulo 1. NUEVAS ETIQUETAS Y ATRIBUTOS DE HTML5

1.7 Panorama de las nuevas APIs y compatibilidad con dispositivos móviles

Además de etiquetas y atributos, HTML5 trajo un conjunto de APIs (Interfaz de Programación de Aplicaciones)[cite: 10]. Una API es el conjunto de funciones que el navegador pone a disposición de JavaScript para hacer algo que el marcado por sí solo no puede: dibujar, guardar datos, pedir la posición o mantener una conversación con el servidor[cite: 10].

Capacidades incorporadas al navegador

Área Funcionalidades de la API
Dibujar Lienzo de mapa de bits (Canvas) y gráficos vectoriales (SVG)[cite: 10].
Reproducir Vídeo y audio nativos con control por código y subtítulos[cite: 10].
Guardar en el equipo Almacenamiento de clave-valor (localStorage) y bases de datos en cliente (IndexedDB)[cite: 10].
Interactuar Arrastrar y soltar (Drag and Drop), pantalla completa y avisos/notificaciones[cite: 10].
Situar Coordenadas del dispositivo con permiso explícito (Geolocation API)[cite: 10].
Comunicar Conexión permanente en dos sentidos entre cliente y servidor (WebSockets)[cite: 10].

La otra pata de HTML5: Adaptación a Móviles

Cuando la web se desplazó a los teléfonos, HTML5 respondió con herramientas de adaptación[cite: 10]:

  • Etiqueta Viewport: <meta name="viewport" content="width=device-width, initial-scale=1.0"> le indica al navegador que use el ancho real del dispositivo en lugar de fingir una pantalla de escritorio[cite: 10].
  • Teclados adaptados: Los tipos de input especifican el teclado táctil adecuado (números, correo, URL)[cite: 10].
  • Eventos táctiles: Eventos diseñados para la interacción con el dedo en lugar del ratón[cite: 10].

⚠️ ATENCIÓN: Detección de Características

Ninguna de estas capacidades se debe dar por supuesta[cite: 10]. Antes de usar una API, comprueba desde JavaScript si el navegador la soporta y prepara una alternativa si no es así[cite: 10]. Es la base de la mejora progresiva[cite: 10].
