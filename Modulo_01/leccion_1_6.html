Módulo 1. NUEVAS ETIQUETAS Y ATRIBUTOS DE HTML5

1.6 Atributos globales y específicos de las nuevas etiquetas

Los atributos son palabras clave que se escriben dentro de la etiqueta y modifican su comportamiento[cite: 10]. Los globales pueden aplicarse a cualquier elemento; los específicos solo tienen sentido en etiquetas concretas (como poster en <video> o required en <input>)[cite: 10].

Atributos Globales Clave

Atributo global Qué hace
id Identificador único de un elemento en el documento; lo usan CSS, JavaScript y enlaces internos[cite: 10].
class Asigna una o varias clases (separadas por espacios) para compartir estilos[cite: 10].
lang y dir Idioma del contenido y dirección de escritura (ltr / rtl)[cite: 10].
title Información adicional que aparece al detener el ratón sobre el elemento[cite: 10].
data-* Novedad HTML5: atributos de datos personalizados (data-precio, data-id) legibles desde JS mediante dataset[cite: 10].
hidden Novedad HTML5: oculta el elemento sin necesidad de CSS[cite: 10].
contenteditable Novedad HTML5: hace editable el contenido directamente en la página[cite: 10].
translate Indica si el texto debe traducirse automáticamente o no (translate="no")[cite: 10].
tabindex y accesskey Controlan el orden de foco con el teclado y los atajos de teclado[cite: 10].
style CSS en línea sobre la propia etiqueta[cite: 10].

Atributos Específicos Destacados

  • Multimedia: autoplay, controls, loop, muted, poster, preload[cite: 10].
  • Formularios: placeholder, required, pattern, multiple, autofocus[cite: 10].
  • Enlaces: Atributo download en las etiquetas <a>, que convierte en descarga directa el enlace a un archivo[cite: 10].

Preguntas Frecuentes

  • ¿Qué pasó con las etiquetas antiguas? HTML5 declaró obsoletas las etiquetas puramente presentacionales (<center>, <font>, <big>, <blink>, <frame>, <strike>) para delegar todo el estilo a CSS[cite: 10].
  • ¿El div ha muerto? No. <div> y <span> siguen siendo correctos para agrupar contenido sin significado especial[cite: 10].
  • ¿Cómo se lee un atributo data-* desde JS? Mediante la propiedad dataset[cite: 10]. Para data-autor="Ana" data-fecha="2026", se accede con elem.dataset.autor y elem.dataset.fecha[cite: 10].

💡 IDEA CLAVE: Separación de Responsabilidades

HTML se encarga de la estructura y semántica; CSS de la presentación y aspecto visual; JavaScript del comportamiento interactivo.
