Módulo 1. NUEVAS ETIQUETAS Y ATRIBUTOS DE HTML5

1.1 El desarrollo web en cliente: qué hace cada pieza

Las tres capas del Front-End

  • HTML: Estructura y significado semántico del contenido.
  • CSS: Presentación, diseño visual y maquetación.
  • JavaScript: Comportamiento dinámico e interactividad con el usuario.

Pasos del navegador al cargar una página

  1. Descarga de archivos desde el servidor.
  2. Conversión del HTML en el árbol DOM (Document Object Model).
  3. Aplicación de estilos CSS a cada nodo.
  4. Renderizado / Pintado de la página en pantalla.
  5. Ejecución de JavaScript para manipular el DOM según la interacción.

Herramientas clave

DevTools del navegador: Imprescindibles para inspeccionar el DOM activo, depurar errores en consola y monitorear el rendimiento.
