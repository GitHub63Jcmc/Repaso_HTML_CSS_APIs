2.3 Efectos de texto

El texto es el contenido principal de la web[cite: 8]. CSS3 amplió las posibilidades tipográficas permitiendo sombras, control de desbordamiento sin romper maquetaciones y efectos decorativos avanzados[cite: 8].

Sombra de texto (text-shadow)

Funciona igual que box-shadow (desplazamiento H, desplazamiento V, desenfoque y color) y permite encadenar varias sombras separadas por comas[cite: 8].

/* Ejemplos de text-shadow */
.sombra-simple {
  text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.7);
}

.sombra-glow {
  color: #3b82f6;
  text-shadow: 0 0 8px #3b82f6, 
               0 0 15px #1d4ed8;
}

Cuando el texto no cabe

Propiedad Qué hace
text-overflow: ellipsis Sustituye por puntos suspensivos (...) el texto que no cabe[cite: 8].
overflow-wrap: break-word Permite partir una palabra muy larga para evitar que desborde la caja[cite: 8].
word-break: break-all Control agresivo para romper palabras en cualquier carácter[cite: 8].
hyphens: auto Divide palabras largas usando guiones según el idioma (lang="es")[cite: 8].
white-space: nowrap Impide el salto de línea automático obligando al texto a estar en una fila[cite: 8]. 
/* Solución limpia con Puntos Suspensivos */
.titulo-recortado {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

/* Partir palabras largas */
.texto-seguro {
  overflow-wrap: break-word;
}

Otros ajustes tipográficos y Contornos

  • text-transform: Controla mayúsculas y minúsculas (uppercase, lowercase, capitalize)[cite: 8].
  • letter-spacing: Ajusta el espaciado entre letras[cite: 8].
  • line-height: Controla la altura de línea (interlineado)[cite: 8].
  • -webkit-text-stroke: Dibuja un contorno alrededor de las letras[cite: 8].
/* Espaciado y Contorno de texto */
.texto-espaciado {
  letter-spacing: 3px;
  text-transform: uppercase;
}

.texto-stroke {
  color: transparent;
  -webkit-text-stroke: 1.5px #38bdf8;
}

💡 IDEA CLAVE: Trilogía para puntos suspensivos

Para que text-overflow: ellipsis funcione correctamente, siempre debes aplicar estas 3 propiedades juntas[cite: 8]:

white-space: nowrap;
overflow: hidden;
text-overflow: ellipsis;
