2.11 Consultas de medios y diseño adaptable

Las **consultas de medios** (media queries) permiten aplicar reglas condicionales en función de las características del dispositivo (ancho de ventana, orientación o preferencias del usuario)[cite: 11]. Son la pieza clave para lograr un **diseño adaptable (Responsive Web Design)**[cite: 11].

¿Qué se puede preguntar en una Media Query?

Condición Qué comprueba
min-width / max-width Ancho de la ventana del navegador[cite: 11].
orientation Orientación de la pantalla (portrait / landscape)[cite: 11].
prefers-color-scheme Preferencia de tema del sistema (dark / light)[cite: 11].
prefers-reduced-motion Si el usuario ha pedido reducir animaciones por accesibilidad[cite: 11].
hover / pointer Si el dispositivo usa cursor preciso (ratón) o táctil (dedo)[cite: 11]. 
/* Mobile-First: Estilos base para móvil */
.tarjeta-grid {
  display: grid;
  grid-template-columns: 1fr;
}

/* Tablet (>= 600px) */
@media (min-width: 600px) {
  .tarjeta-grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Escritorio (>= 900px) */
@media (min-width: 900px) {
  .tarjeta-grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

Buenas Prácticas de Maquetación Adaptable

  • Enfoque Mobile-First: Escribir primero el código para pantallas pequeñas y usar min-width para ir añadiendo complejidad a medida que crece el espacio[cite: 11].
  • Puntos de corte por diseño: Define los breakpoints en base a cuando el diseño "se rompe", no ajustándote a modelos específicos de teléfono o tablet[cite: 11].
  • Meta Viewport imprescindible: Sin <meta name="viewport" content="width=device-width, initial-scale=1.0"> en el <head>, el navegador móvil simulará una pantalla de escritorio encogida[cite: 11].

💡 IDEA CLAVE: Adaptable no significa recortado

Una buena web adaptable reorganiza los contenidos, amplía zonas táctiles en móvil o muestra barras laterales en escritorio, pero nunca oculta información esencial solo por estar en pantalla pequeña[cite: 11].
