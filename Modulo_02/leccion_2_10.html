Módulo 2. NOVEDADES DE CSS3

2.10 Texto en columnas

CSS3 incorporó un mecanismo específico para maquetar **texto corrido en columnas estilo periódico**[cite: 11]. El contenido fluye de manera automática desde el final de una columna hacia la parte superior de la siguiente[cite: 11].

Propiedades del diseño en columnas

Propiedad Qué hace
column-count Número exacto de columnas[cite: 11].
column-width Ancho mínimo orientativo de cada columna[cite: 11].
columns Abreviatura (ej. columns: 3 200px)[cite: 11].
column-gap Separación horizontal entre columnas[cite: 11].
column-rule Línea divisoria vertical entre columnas[cite: 11].
column-span: all Hace que un título o elemento cruce todas las columnas[cite: 11].
break-inside: avoid Evita que un bloque se parta por la mitad al cambiar de columna[cite: 11]. 
/* Layout periodístico multicolumna */
.articulo-periodico {
  columns: 3 180px;
  column-gap: 1.5rem;
  column-rule: 1px solid #334155;
}

.titular-principal {
  column-span: all;
}

Titular Expandido

El diseño de texto en columnas permite adaptar grandes bloques de lectura de forma ordenada[cite: 11]. Cuando el texto llega al final de la caja, salta automáticamente al encabezado de la siguiente columna[cite: 11].

Es perfecto para editoriales, artículos largos o listas extensas[cite: 11]. Mantiene las líneas de texto equilibradas[cite: 11].

Evitar la ruptura de bloques (`break-inside`)

Cuando incluimos tarjetas, imágenes o citas dentro de un flujo multi-columna, es fundamental usar break-inside: avoid para que no queden divididas de forma antiestética entre dos columnas[cite: 11].

/* Evitar cortes entre columnas */
.tarjeta-destacada {
  break-inside: avoid;
  background-color: #0f172a;
  border: 1px solid #3b82f6;
  padding: 10px;
}
Bloque Integro: Esta tarjeta nunca se dividirá en dos columnas distintas gracias a break-inside[cite: 11].

El resto del texto fluido continuará repartiéndose por el contenedor sin interrumpir la integridad del elemento[cite: 11].

💡 IDEA CLAVE: Uso adecuado de columnas

No utilices esta propiedad para maquetar la estructura de la web (cabecera, sidebar, contenido)[cite: 11]. Las columnas CSS están diseñadas para texto corrido, artículos largos o listados[cite: 11]. Para estructuras completas de página, utiliza siempre Flexbox o Grid Layout[cite: 11].
