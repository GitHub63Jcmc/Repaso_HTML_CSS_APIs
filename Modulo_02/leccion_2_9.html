2.9 Retículas: Grid Layout

CSS Grid Layout es un sistema de maquetación bidimensional (filas y columnas)[cite: 11]. Mientras que Flexbox organiza elementos principalmente en una sola dirección, Grid impone una estructura sobre el contenedor donde posicionar los elementos[cite: 11].

Definir Columnas, Unidades `fr` y Span

La unidad de fracción fr representa porciones del espacio libre disponible[cite: 11]. Además, con grid-column: span X un elemento puede ocupar varias columnas[cite: 11].

/* Columnas proporcionales y extensión */
.contenedor-grid {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  gap: 10px;
}

.item-ancho {
  grid-column: span 2; /* Ocupa 2 columnas */
}

Grid Adaptable sin Media Queries (`auto-fit` y `minmax`)

Combinando repeat(auto-fit, minmax(min, max)) la retícula se reorganiza automáticamente al cambiar el ancho del contenedor sin necesidad de escribir media queries[cite: 11].

/* Galería adaptable automática */
.grid-adaptable {
  display: grid;
  grid-template-columns: 
    repeat(auto-fit, minmax(100px, 1fr));
  gap: 10px;
}

Maquetación por Áreas (`grid-template-areas`)

Permite dibujar la estructura visualmente asignando nombres a las zonas del layout[cite: 11].

/* Definición de áreas en el contenedor */
.layout-app {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 1fr 2fr;
  gap: 8px;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

💡 IDEA CLAVE: ¿Grid o Flexbox?

Usa Grid para la estructura macro o global de la página (cabecera, barra lateral, cuerpo principal, pie)[cite: 11]. Usa Flexbox para alinear los componentes dentro de cada una de esas zonas (botones, listas, menús)[cite: 11].
