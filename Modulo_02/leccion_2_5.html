2.5 Transformaciones

La propiedad transform modifica la geometría de un elemento sin alterar el flujo del documento[cite: 8]. El elemento se mueve, gira o escala, pero el espacio original que ocupaba sigue reservado sin afectar a los elementos contiguos[cite: 8].

Transformaciones 2D Básicas

Función Qué hace Ejemplo
translate(x, y) Desplaza el elemento en ejes X e Y[cite: 8]. translate(15px, -10px)[cite: 8]
rotate(deg) Gira el elemento los grados indicados[cite: 8]. rotate(15deg)[cite: 8]
scale(factor) Escala/agrandar o encoge el elemento[cite: 8]. scale(1.15)[cite: 8]
skew(deg) Inclina la figura sobre sus ejes[cite: 8]. skewX(-12deg)[cite: 8] 
/* Ejemplos de transformaciones 2D */
          
  .caja-translate { 
    transform: translate(15px, -10px); 
  }
  .caja-rotate { 
    transform: rotate(15deg); 
  }
  .caja-scale  { 
    transform: scale(1.15); 
  }
  .caja-skew   { 
    transform: skewX(-12deg); 
  }

El orden importa y transform-origin

Al encadenar transformaciones (ej. transform: translate(20px) rotate(45deg);), el orden modifica el resultado visual final[cite: 8]. Además, con transform-origin puedes cambiar el punto de anclaje del elemento (por defecto en el centro)[cite: 8].

/* Anclaje en la esquina superior izquierda */
        .puerta-giratoria {
          transform-origin: top left;
          transform: rotate(20deg);
        }

Transformaciones 3D

  • perspective: Otorga profundidad 3D al contenedor padre[cite: 8].
  • transform-style: preserve-3d: Mantiene la perspectiva 3D en los hijos[cite: 8].
  • backface-visibility: hidden: Oculta la parte posterior del elemento al girarlo[cite: 8].
/* Efecto Flip Card 3D */
        .contenedor-padre {
          perspective: 600px;
        }
        .tarjeta-3d {
          transform-style: preserve-3d;
          transition: transform 0.6s;
        }
        .tarjeta-3d:hover {
          transform: rotateY(180deg);
        }
        .cara {
          backface-visibility: hidden;
        }

💡 IDEA CLAVE: Animación fluida

Por sí sola, la propiedad transform es instantánea[cite: 8]. Para ver un movimiento continuo o animación fluida, se debe combinar con la propiedad transition o animaciones con @keyframes[cite: 8].
