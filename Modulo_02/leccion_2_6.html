2.6 Transiciones

Una **transición** anima el paso entre dos estados de forma gradual y fluida[cite: 9]. Permite cambiar propiedades sin saltos bruscos al interactuar con el usuario (ej. al pasar el ratón o activar una clase)[cite: 9].

Subpropiedades y Abreviatura

Subpropiedad Qué controla Valores habituales
transition-property Propiedades que se van a animar[cite: 9]. all, transform, background-color[cite: 9]
transition-duration Duración del cambio[cite: 9]. .3s, 400ms[cite: 9]
transition-timing-function Curva de velocidad de la animación[cite: 9]. ease, linear, cubic-bezier()[cite: 9]
transition-delay Tiempo de espera antes de comenzar[cite: 9]. 0s, .1s[cite: 9] 
/* Declaración correcta en el estado NORMAL */
.boton {
  background-color: #1e293b;
  color: #38bdf8;
  /* Abreviatura: propiedad tiempo curva */
  transition: background-color 0.3s ease, 
              transform 0.3s ease;
}

.boton:hover {
  background-color: #38bdf8;
  color: #0f172a;
  transform: translateY(-3px);
}

Curvas de Velocidad (Timing Functions)

Determinan cómo acelera o desacelera la animación durante su recorrido (haz hover sobre el contenedor para probarlas)[cite: 9]:

/* Diferentes funciones de tiempo */
.caja-ease {
  transition: transform 0.8s ease;
}
.caja-linear {
  transition: transform 0.8s linear;
}
.caja-bounce {
  transition: transform 0.8s 
    cubic-bezier(0.68, -0.55, 0.27, 1.55);
}

Rendimiento y Propiedades Animables

  • Alto rendimiento (60fps): Animaciones procesadas por la tarjeta gráfica usando transform (para desplazar/escalar) y opacity (para visibilidad)[cite: 9].
  • Evitar animar: Propiedades que fuerzan al navegador a recalculaciones completas de maquetación como width, height, top, left o margin[cite: 9].
/* Transición optimizada de visibilidad */
.tarjeta-fade {
  opacity: 0.5;
  transition: opacity 0.4s ease, 
              border-color 0.4s ease;
}

.tarjeta-fade:hover {
  opacity: 1;
  border-color: #10b981;
}

💡 IDEA CLAVE: Dónde declarar la transición

La regla transition debe ubicarse siempre en la regla principal del elemento (el estado base)[cite: 9]. Si se escribe dentro de :hover, la animación solo funcionará al entrar con el ratón, pero el efecto se cortará abruptamente al retirarlo[cite: 9].
