2.7 Animaciones con @keyframes

Las **animaciones** en CSS3 van más allá de las transiciones: no necesitan un evento que las active y pueden encadenar múltiples fases o ejecutarse en bucle infinito[cite: 10]. Se componen de dos pasos: la definición de reglas con @keyframes y su aplicación mediante animation[cite: 10].

Propiedades de Animación

Subpropiedad Qué controla
animation-name Nombre de la regla @keyframes declarada[cite: 10].
animation-duration Tiempo del ciclo completo (ej. 2s)[cite: 10].
animation-timing-function Velocidad del movimiento (linear, ease, steps())[cite: 10].
animation-iteration-count Número de veces que se repite (1, 5, infinite)[cite: 10].
animation-fill-mode Estado final tras terminar (forwards mantiene el último fotograma)[cite: 10].
animation-play-state Pausa o reanuda la animación (running, paused)[cite: 10]. 
/* 1. Definición de fotogramas */
@keyframes girar {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}

/* 2. Aplicación abreviada */
.spinner {
  animation: girar 1s linear infinite;
}

Fases con porcentajes y control de estado

Usar porcentajes permite definir estados intermedios (0%, 50%, 100%)[cite: 10]. Además, con animation-play-state: paused podemos congelar el movimiento al interactuar con el elemento[cite: 10].

/* Animación multinivel */
@keyframes pulso {
  0%   { transform: scale(1); }
  50%  { transform: scale(1.05); }
  100% { transform: scale(1); }
}

.tarjeta-pulso {
  animation: pulso 2s infinite;
}

/* Pausa al hacer Hover */
.elemento-pausable:hover {
  animation-play-state: paused;
}
Efecto Pulso
Hover = Pausa

Preguntas Frecuentes

  • ¿Transición o Animación? Usa transición para cambios sencillos A $\rightarrow$ B disparados por el usuario[cite: 10]. Usa animación si necesitas bucles, inicio automático o múltiples estados intermedios[cite: 10].
  • ¿Hasta dónde llega CSS frente a JS? CSS gestiona de forma eficiente la parte declarativa[cite: 10]. JavaScript se reserva para sincronizaciones según la interacción del usuario o eventos del DOM[cite: 10].
  • Degradación elegante: Si un navegador antiguo no entiende una regla de animación, simplemente la ignora y muestra la interfaz estática sin fallar[cite: 10].

💡 IDEA CLAVE: Rendimiento a 60 FPS

Al igual que con las transiciones, prioriza animar únicamente transform y opacity[cite: 10]. El motor del navegador procesará estas animaciones mediante la GPU, garantizando fluidez sin tirones[cite: 10].
