2.4 Tipografías externas con @font-face

La regla @font-face elimina la limitación de usar solo fuentes del sistema, permitiendo **descargar una tipografía junto con la página** e integrarla de forma nativa en la hoja de estilos[cite: 9].

Uso y sintaxis de @font-face

Se declara el nombre con font-family y la ruta del archivo con src: url()[cite: 9]:

/* Declaración de la fuente externa */
@font-face {
  font-family: 'MiFuente';
  src: url('../fonts/mi-fuente.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

/* Aplicación en un selector */
.titulo-destacado {
  font-family: 'MiFuente', sans-serif;
}

Lo que hay que decidir al usarla

  • Formato estándar (WOFF2): Formato comprimido diseñado para la web y compatible con navegadores modernos[cite: 9].
  • Una declaración por variante: Negritas y cursivas de una misma familia requieren su propio bloque @font-face enlazado por font-weight y font-style[cite: 9].
  • Estrategia de carga (font-display):
    • swap: Muestra la fuente de reserva de inmediato y cambia al cargar la definitiva (recomendado)[cite: 9].
    • block: Mantiene el texto invisible un breve periodo mientras descarga[cite: 9].
  • Alojamiento propio: Lo más profesional es alojar las fuentes directamente en tu proyecto[cite: 9].
  • Fuentes Variables: Un único archivo que soporta cualquier rango de pesos (ej. font-weight: 460)[cite: 9].
/* Carga optimizada con font-display */
@font-face {
  font-family: 'RobotoCustom';
  src: url('/fonts/roboto.woff2') format('woff2');
  font-display: swap; /* Evita el texto invisible */
}

/* Uso de Fuente Variable */
.texto-variable {
  font-family: 'InterVariable', sans-serif;
  font-weight: 550; /* Peso personalizado */
}
font-display: swap; (Texto visible siempre)

💡 IDEA CLAVE: Rendimiento y WOFF2

Cada archivo de fuente es una descarga adicional para el cliente[cite: 9]. Procura usar exclusivamente el formato WOFF2 y limita la selección a 2 o 3 pesos máximo por familia tipográfica para evitar ralentizar la carga del portal[cite: 9].
