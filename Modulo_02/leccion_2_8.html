2.8 Cajas flexibles: Flexbox

Flexbox es el sistema de maquetación unidimensional de CSS3 diseñado para distribuir espacio y alinear elementos a lo largo de un solo eje (en fila o columna)[cite: 11]. Se activa aplicando display: flex sobre el contenedor padre[cite: 11].

Propiedades en el Contenedor

Propiedad Eje Qué hace
justify-content Principal Distribuye el espacio sobrante (flex-start, center, space-between, space-around, space-evenly)[cite: 11].
align-items Cruzado Alinea los elementos en vertical/eje secundario (stretch, center, flex-start, flex-end)[cite: 11].
flex-wrap - Permite envolver en múltiples líneas si los elementos no caben (nowrap, wrap)[cite: 11].
gap Ambos Define la separación exclusivamente entre ítems flex[cite: 11]. 
/* Distribución en eje principal y cruzado */
.contenedor {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 12px;
}

Propiedades en los Hijos (Flex Items)

  • flex-grow: Determina cuánto crece un hijo para ocupar el espacio sobrante[cite: 11].
  • flex-shrink: Cuánto se encoje si falta espacio (poner 0 evita que se deforme)[cite: 11].
  • flex-basis: Tamaño base inicial antes de repartir el espacio disponible[cite: 11].
  • align-self: Permite a un hijo sobrescribir la alineación cruzada de align-items[cite: 11].
  • Shorthand: flex: 1 equivale a flex: 1 1 0%[cite: 11].
/* Crecimiento proporcional y alineación individual */
.item-1 { flex-grow: 1; }
.item-2 { flex-grow: 2; } /* Crece el doble */
.item-3 { align-self: flex-end; }

💡 IDEA CLAVE: Ventaja de `gap` sobre `margin`

Usar gap elimina la necesidad de trucos antiguos con márgenes o pseudo-clases :last-child[cite: 11]. La propiedad gap añade espacio únicamente entre los ítems internos, dejando limpios los bordes exteriores del contenedor padre[cite: 11].
